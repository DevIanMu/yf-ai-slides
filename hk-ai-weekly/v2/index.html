本页是响应"内容太薄、要给用户可探索空间"反馈的调整版：V1 每条内容截到一句话，V2 改为按自选股聚合的完整档案卡，全部内容规则级抽取自 Gangtise 已有数据（一页通全文/投研线索/个股看点/热点话题），零 LLM 改写、零新增 API 调用。

  • 卡片内容：完整看点 + 一页通「公司近况跟踪」前 2 条 + 投研线索每只最多 3 条（摘要 200 字）+ 命中热点话题 + 未来催化事件 3 条与「关键观察指标」3 条 + 风险提示首条。
  • 合规：机构口径段落经《Demo需求文档》术语黑名单做句级过滤（命中整句丢弃），如汇丰看点因含"估值修复"被整句过滤后留空。这是规则过滤的保守效果，不等同于上线前的合规改写层。
